# Prévia do site · Dra. Luara Cabral · Dermatologia

Prévia de apresentação feita pela RK Performance (outubro de 2026). Não é o site oficial da médica: textos e dados estão marcados "a confirmar" e a página não é indexada (`noindex` + `robots.txt`).

- `index.html`: home.
- `bioestimulador-de-colageno-guarapuava/`: exemplo de página de procedimento.
- `assets/`: CSS e JS.
- `media/`: fotos enviadas pela própria clínica ao Google e trechos de reels públicos da Dra., recortados para a prévia. Nenhuma imagem de paciente.

Os botões de WhatsApp e telefone abrem um aviso de demonstração. No site final, abrem o WhatsApp do consultório com a mensagem de cada página.
